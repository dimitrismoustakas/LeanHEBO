# Security policy

## Supported releases

LeanHEBO is an early-stage project. Security fixes are provided for the latest published
release only; older releases, pre-releases, and development snapshots are not supported.
Users should upgrade before reporting an issue that is already fixed in a newer release.

## Reporting a vulnerability

Do not open a public issue. Submit a
[private GitHub security advisory](https://github.com/dimitrismoustakas/LeanHEBO/security/advisories/new)
with the affected version or commit, impact, reproduction steps, and relevant environment
details. Please allow the maintainers to investigate and coordinate a fix before public
disclosure.
